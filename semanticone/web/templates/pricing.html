Questions

What counts as a query? Each successful metrics query from the explorer, REST API or an AI agent through MCP. Validation, compiling to SQL and failed queries are free.

Do you store our data? No. Queries run in your warehouse and results are streamed back; we store your model definitions, encrypted connection credentials and query logs (the SQL and row counts, not result rows).

Can we self-host? Yes, on Enterprise. SemanticOne ships as a single container image.
