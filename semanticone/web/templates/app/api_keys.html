Connect an AI agent (MCP)

Server URL: {{ settings.base_url }}/mcp · Auth: Authorization: Bearer <key>

Claude Code

claude mcp add --transport http semanticone \
  {{ settings.base_url }}/mcp \
  --header "Authorization: Bearer {{ new_key or 'so_live_...' }}"

JSON config (Cursor and other clients)

{
  "mcpServers": {
    "semanticone": {
      "url": "{{ settings.base_url }}/mcp",
      "headers": {"Authorization": "Bearer {{ new_key or 'so_live_...' }}"}
    }
  }
}

Agents get list_models, describe_model, query_metrics, compile_sql and validate_model. Each successful query_metrics call counts as one query.

REST API

curl -s {{ settings.base_url }}/api/v1/models/{{ models[0].slug if models else 'your-model' }}/query \
  -H "Authorization: Bearer $SEMANTICONE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"metrics": ["{{ 'total_revenue' if models else 'revenue' }}"], "limit": 10}'
